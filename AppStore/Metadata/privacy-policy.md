# Work Island Privacy Policy

Last updated: August 3, 2026

Work Island does not collect, transmit, track, sell, or share personal data.

## Local data

Activities, notes, timer state, and activity history are stored locally in Work Island's macOS app container. This information is not sent to the developer or any third party.

## Import and export

Work Island can import or export a JSON backup only after the user explicitly chooses a file through the standard macOS file picker. The app does not scan other files.

## Accounts, analytics, and advertising

Work Island has no account system, analytics, advertising, tracking technologies, or third-party SDKs.

## Your control

Users can edit or delete individual records in the app and can export a local backup. Removing the app does not necessarily remove its container data automatically; macOS storage tools can be used to remove it separately.

## Changes

If Work Island's data practices change, this policy and the App Store privacy disclosure will be updated before the changed version is released.

## Contact

For privacy questions, use the [Work Island support page](https://shikaland0927-ctrl.github.io/work-island/support.html).
