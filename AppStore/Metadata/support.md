# Work Island Support

## Quick help

- Move the pointer to the black panel at the top center of the display to reveal controls.
- Click the panel if hover is unavailable.
- Use the Window symbol in the notch panel to show the main window.
- Use Work Island > Quit from the standard application menu to quit completely.
- Use File > Export to create a local JSON backup.
- Finish or discard an active timer before using File > Import.

## When reporting a problem

Include the Work Island version, Mac model and chip, macOS version, exact steps, expected result, actual result, and a screenshot or screen recording when possible. Do not attach a backup file if its activity names or notes contain private information.

## Contact

[Open a public GitHub support issue](https://github.com/shikaland0927-ctrl/work-island/issues/new?title=Work%20Island%20support%3A%20). Do not include private activity names, notes, backups, or other personal information.
