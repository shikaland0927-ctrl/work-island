Support

How can we help?

Most Work Island controls are available from the notch panel or menu bar.

Quick help

  • Move the pointer to the black panel at the top center of the display to reveal controls.
  • Click the panel if hover is unavailable.
  • Use the menu-bar item to show the main window or quit Work Island.
  • Use File → Export to create a local JSON backup.
  • Finish or discard an active timer before using File → Import.

Report a problem

Open a GitHub issue and include the Work Island version, Mac model and chip, macOS version, steps to reproduce, expected result, and actual result.

Issues are public. Do not attach backups or include private task names, notes, or other personal information.

Open a support issue

Data

Tasks, notes, timer state, and session history are stored locally in the app's macOS container. Work Island has no account or cloud sync.
