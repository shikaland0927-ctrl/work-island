Privacy

Privacy Policy

Last updated: August 3, 2026

Work Island does not collect, transmit, track, sell, or share personal data.

Local data

Tasks, notes, timer state, and work-session history are stored locally in Work Island's macOS app container. This information is not sent to the developer or any third party.

Import and export

Work Island can import or export a JSON backup only after you explicitly choose a file through the standard macOS file picker. The app does not scan other files.

Accounts, analytics, and advertising

Work Island has no account system, analytics, advertising, tracking technologies, cloud sync, or third-party SDKs.

Your control

You can edit or delete individual records in the app and export a local backup. Removing the app does not necessarily remove its container data automatically; macOS storage tools can be used to remove it separately.

Support links

The support page links to GitHub Issues. Visiting GitHub is optional and occurs outside Work Island; information submitted there is handled under GitHub's own privacy terms.

Changes

If Work Island's data practices change, this policy and the App Store privacy disclosure will be updated before the changed version is released.

Contact

For privacy questions, use the Work Island support page.
